# Configurable Views

**Build your own views of the Rancher Home page and cluster dashboard.**

### Overview
Configurable Views lets you arrange the Home page and each cluster's dashboard from widgets: tables of any resource, cluster summaries and capacity, events, alerts, metrics, links, banners and tabs. A page can have several views, and the views bar switches between them. Your own views are saved to your account, and administrators can also publish views.

The views bar stays hidden until you open it from the header button or with **Shift+V**. You can switch Configurable Views off for yourself at any time, and Rancher's own pages show again.

### Example Use Cases
* **Platform Teams**: Put the clusters and resources you watch most on the Home page.
* **Cluster Operators**: Keep a dashboard view for each job, such as workloads, networking or storage, and switch between them.

### Deployment Path
* **Prerequisites**: Rancher Prime 2.16 or newer.
* **First Step**: Install **Configurable Views** from the Extensions catalog, open the Home page or a cluster's dashboard, then open the views bar and edit the view.
